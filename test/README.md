# 柜体模型工艺自动拆解（第一步 MVP）

## 用途
输入一个装配好的柜体模型（多零件 STL，装配坐标系），系统自动拆解出装配工艺链。

## 使用
1. 把新柜体的零件 STL 放入 `test/models/<柜体名>/`（或任意文件夹）
2. 运行 `python3 test/import_cabinet_ui.py`
3. 界面里：① 导入模型文件夹 → ② 解析并拆解工艺链 → ③ 应用到场景（可选，需 CoppeliaSim 已打开且停止）
4. 或命令行离线拆解：`python3 test/decompose_assembly.py <文件夹>`

## 当前能力（MVP）
- STL 解析（二进制/ASCII）、包围盒/重心
- 接触图（包围盒邻近）
- 装配约束启发式：支撑关系（A 顶面托 B 底面）、包容关系（A 包含 B）
- 拓扑排序（高度升序断平局）→ 装配顺序 DAG
- 关键词 + 几何分类（壳体/平板/导轨/器件/紧固件）→ 工艺类型
- 能力表映射到 8 臂产线（R1 上料 / R2-R3 平板与杆件 / R5-R6 器件 / R7 锁付 / R8 分拣）
