# 八机械臂最小算法验证总报告

## 验证范围

本轮采用当前八机械臂轨迹库中的30条动作、R1–R8固定分工、三级公共区、标准与减配电控柜配方进行最小验证。验证覆盖调度、统计稳定性、权重消融、区域时间窗CBS、R7/R8优先级协调以及RRT-Connect搜索模块。

本轮不声明连续几何碰撞、控制器实时性或实机安全已经通过。

## 结果汇总

| 模块 | 最小试验 | 结果 | 判定 |
|---|---|---|---|
| 八臂流水调度 | 串行、FIFO、动态调度固定四柜对比 | FIFO相对串行缩短总完工时间42.5%；动态策略相对FIFO降低加权延期55.5% | 通过 |
| 统计稳定性 | 200组随机订单配对试验 | 加权延期差值95% CI为[-7453.94, -5093.99]帧；急单完成差值95% CI为[-1182.23, -565.17]帧 | 通过 |
| 权重消融与灵敏度 | 4项消融、4项±50%扰动 | 去掉优先级项后平均加权延期由32631.2增至34866.1；提高优先级权重后降至31798.2 | 通过，关键路径项在固定三级路线中不敏感 |
| 区域级CBS | 相向、双区域交叉、急单让行、三臂连锁 | 四类用例均在100节点预算内获得无时间窗冲突解，最大展开22节点 | 通过 |
| R7/R8协调 | 无协调、固定普通任务优先、优先级CBS | 冲突数由1降为0；CBS保持急单完成时刻11，固定普通任务优先为23 | 通过 |
| RRT-Connect最小搜索 | 6条代表路径×10个随机种子 | 60次参考走廊搜索全部成功，P95计算时间0.16–115.16 ms | 算法模块通过；待在线几何验证 |

## 可用于报告的结论

基于当前八机械臂30条已固化轨迹和三级公共区约束构建离散事件验证模型。固定四柜样例表明，三级流水FIFO相对整柜串行可将总完工时间缩短42.5%；在总完工时间保持不变的情况下，综合动态策略相对FIFO将加权延期降低55.5%，急单响应时间缩短82.3%，急单完成时间缩短42.3%。在200组随机订单配对试验中，动态策略相对FIFO的加权延期和急单完成时间差值的95%置信区间均低于零，说明改善并非仅由单一固定订单造成。

区域级CBS在相向占用、双区域交叉、急单让行和三臂连锁四类时间窗冲突中均获得无冲突解。R7/R8用例进一步表明，优先级CBS能够在消除公共区冲突的同时避免急单等待。六条代表关节路径上的60次RRT-Connect参考走廊搜索全部成功，说明候选路径搜索模块具备基本可执行性；由于本轮未完成在线场景连接，该结果仅作为搜索算法验证，连续几何碰撞仍由后续CoppeliaSim预检确认。

灵敏度结果表明，优先级权重对当前多订单场景的加权延期和急单完成时间影响明显，等待项影响较小；关键路径项在固定三级路线下没有改变派发结果。因此报告中不应宣称当前关键路径权重已经获得独立性能收益，而应表述为模型保留项，待增加可选工艺路线后继续验证。
